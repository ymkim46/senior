# 온라인 실버타운

누구나 웹으로 들어와 하루를 함께 보내는 3D 시니어 하우스입니다. 타운 안의 해, 날씨, 시계, 일력, 밥때가 실제와 똑같이 흘러갑니다.

## 무엇을 할 수 있나

- **켜 두기** — 아무것도 누르지 않아도 됩니다. 시간표에 따라 내 모습이 식당, 공방, 피아노 앞, 정원으로 알아서 움직이고, 일정이 바뀔 때마다 종소리와 말로 알려 줍니다.
- **돌아다니기** — 가고 싶은 곳을 누르면 걸어갑니다. 탁자, 나무, 꽃밭, 울타리, 호수 같은 장애물은 알아서 돌아갑니다.
- **조이스틱** — 화면 왼쪽 아래 동그라미를 밀면 그 방향으로 걷습니다 (컴퓨터에서는 방향키나 WASD). 나무, 의자, 탁자, 벽, 물에 막히면 그 옆을 따라 미끄러집니다.
- **앉기** — 의자나 긴 의자를 누르거나 🪑 앉기 단추를 누르면 가까운 빈자리에 가서 앉습니다.
- **말 걸기** — 도우미와 이웃에게 다가가거나 누르면 말을 겁니다. 지배인은 가끔 먼저 찾아와 오늘 날짜, 다음 일정, 날씨를 알려 줍니다. 말은 미리 준비한 문장 중에서 때에 맞게 고릅니다.
- **둘러보기** — 내 모습 뒤에서 눈높이로 따라갑니다. 한 손가락으로 끌면 둘러보고, 두 손가락을 벌리거나 ＋ － 단추로 가까이·멀리 봅니다. 위에서 내려다보면 지붕이 걷혀 안이 보입니다.
- **안내도** — 타운 지도를 열어 라운지, 식당, 공방, 피아노, 텃밭, 꽃길, 쉼터, 체조 마당, 대문 중 한 곳을 누르면 그곳으로 걸어갑니다. 3D 화면에도 곳곳에 이름 팻말이 떠 있습니다.
- **실제 시각** — 해와 달의 위치, 그림자, 저녁 등불, 벽시계, 일력이 한국 시간과 같습니다. 계절에 따라 나무와 꽃이 바뀝니다.
- **내 동네 날씨** — 들어올 때 고른 시·도(또는 휴대폰 위치)의 지금 날씨가 정원에 그대로 내립니다.
- **도우미** — 지배인, 영양사, 운동 선생님이 일정마다 자리를 지키고, 정해진 시간에 보건소 방문 간호사가 찾아옵니다. 도우미는 걷고 손 흔드는 동작이 들어 있는 로봇 모델입니다.
- **호수와 산책길** — 대문 밖으로 나가면 호수를 한 바퀴 도는 산책길, 정자, 낚시터가 있습니다. 산책 시간에는 다 함께 호수를 돕니다.
- **이웃들** — 호숫가를 걷는 이웃, 강아지와 산책하는 이웃, 낚시하는 어르신, 정자에서 바둑 두는 이웃, 텃밭 가꾸는 이웃이 저마다 하루를 보내다가 밥때에는 식당에 모입니다. 가까이 가면 먼저 인사합니다.
- **배경음악** — 잔잔한 가락이 흐릅니다. 음악 파일 없이 화면에서 직접 만들어 내며, 위쪽 🎵 단추로 끕니다.
- **함께 있는 사람들** — 지금 들어와 있는 다른 분들이 보이고, 인사를 건넬 수 있습니다. 건강리더로 들어오면 이름 옆에 표시됩니다.
- 회원가입 없이 이름과 사는 곳만 정해서 들어옵니다. 이름·사는 곳·출석 도장은 그 휴대폰에만 기억됩니다.

## 그림으로 보는 화면

`/rooms.html`은 같은 타운을 그림으로 보여 줍니다. 방마다 그림 한 장(`public/rooms/`)을 쓰고, 그 위에 실제 시각의 빛(낮·노을·밤 등불)과 내 동네의 비·눈을 얹습니다. 시간표에 따라 방이 저절로 바뀌고, 안내도에서 다른 방을 골라 구경할 수 있습니다. 그림은 끌어서 둘러보고 ＋ －로 확대합니다.

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm start            # http://localhost:3000
```

| 환경 변수 | 설명 |
| --- | --- |
| `PORT` | 포트 (기본 3000) |
| `DATA_DIR` | 방문 수를 적는 SQLite 파일 위치 (기본 `./data`) |
| `ROOM_CAP` | 하우스 한 곳의 정원 (기본 40). 넘으면 새 하우스가 자동으로 열립니다 |
| `WEATHER=off` | 실제 날씨를 받지 않고 늘 맑음으로 둡니다 |
| `TRUST_PROXY=1` | 리버스 프록시 뒤에서 `X-Forwarded-For`로 접속자 구분 |

주소 끝에 `?demo`를 붙이면 시간을 돌려 보고 날씨를 바꿔 보는 시험 조작이 나옵니다.

## 설정

타운 이름과 하루 시간표는 `config.json`에서 고칩니다 (저장하면 새로 들어오는 사람부터 반영).

- `time`: 한국 시간 `HH:MM`, `minutes`: 진행 시간
- `announce`: 일정이 시작될 때 크게 보이고 읽어 주는 말, `say`: 도우미의 한마디
- `scene`: 그 시간에 모이는 곳 — `greet`(현관 앞 인사) `meal`(식당) `gym`(정원 체조) `craft`(공방 탁자) `music`(피아노 앞) `nurse`(간호사 방문) `walk`(정원 산책)
- `meal`: `true`면 밥때 색으로 강조합니다

## 구조

- `server.js` — 정적 파일, 시간표·날씨 API, 접속자 위치 동기화(WebSocket), 방문 수 저장
- `public/world.js` — 3D 타운 (three.js, `public/vendor/`에 포함)
- `public/img/` — 들어가는 문에 쓰는 분위기 그림
- `public/models/` — 도우미 로봇 모델 (출처와 사용 조건은 `CREDITS.txt`)
